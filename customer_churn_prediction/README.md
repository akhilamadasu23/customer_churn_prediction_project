# Customer Churn Prediction

An end-to-end machine learning project that predicts whether a customer is likely to churn.

### Skills
Python • Pandas • NumPy • Matplotlib • Scikit-learn • Data Cleaning • EDA • Feature Engineering • Logistic Regression • Random Forest • Model Evaluation

### Workflow
1. Load customer data
2. Handle missing values
3. Explore churn patterns
4. Encode categorical features
5. Scale numerical features
6. Train Logistic Regression and Random Forest
7. Compare Accuracy, Precision, Recall and F1
8. Generate confusion matrices
9. Predict churn probability

> The included dataset is synthetic and created for learning/portfolio use.

### Run
```bash
pip install -r requirements.txt
python churn_prediction.py
```
